# Hi, I'm Simão

BSc in Computer Engineering from the University of Coimbra (LEI), now doing an MSc in Software Engineering at the same university. I focus on backend development, distributed systems and systems integration.

Currently a student researcher at CISUC (Centre for Informatics and Systems of the University of Coimbra), working on software vulnerability detection with LLMs on low-level code representations such as Assembly and Bytecode. I built an experimental pipeline that compares how well LLMs find vulnerability patterns (CWE) in disassembled code against the original source code, using the Juliet Test Suite as benchmark.

I like designing and building the parts of a system that talk to each other: APIs, message brokers, replicated services and the data layer underneath.

**Languages:** Java · Python · C · SQL · TypeScript
**Backend and integration:** Spring Boot · FastAPI · Flask · REST · Java RMI · WebSockets · Apache Kafka (Streams, Connect) · MCP
**Data and infrastructure:** PostgreSQL · Docker · GitHub Actions · GitLab CI · Git
